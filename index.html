Working folder downloaded — commit it, then submit in OLOS

This .zip is your working folder — your whole board as data (state.json) plus the situation and themes as Markdown. The tool has no server; your triad syncs through one shared Git repo, and the manual loop is what keeps any one person from framing alone.

  1. Unzip the folder into your local clone of the triad's shared repository, as your own top-level folder (overwriting your previous version).
  2. Commit & push with three commands: 
    git add .
git commit -m "Update situation map — [your name]"
git push
  3. Git merges your map with your podmates'. A merge conflict isn't an error — it's a conversation: two of you saw the same thing differently, so talk it out, then commit the resolution.
  4. Submit in OLOS: open your cycle → Propose. The wizard asks for your problem situation — the workbook fields, a distilled sentence — and a “Link to your map” — paste the triad repo's URL. Voting happens on the OLOS ballot; the repo is what voters open.

This manual loop is intentional. It prevents the Lone Warrior syndrome — no single person's export overwrites everyone else's work without Git making you negotiate.
